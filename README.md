# Harshit Kushwaha — Portfolio

React + Vite + Tailwind CSS + Framer Motion portfolio.

## Run locally

    npm install
    npm run dev

## Update content

All text, links, projects, skills and experience live in `src/data/portfolio.js`.

## Add project screenshots

1. Put the image in `public/images/`, for example `chat-app.png`.
2. In `src/data/portfolio.js`, set the project's `image` to `'/images/chat-app.png'`.

## Replace the resume

Replace `public/resume/Harshit_Kushwaha_Resume.pdf` with the new PDF, keeping the same file name, or update `resumeUrl` in `profile`.

## Deploy

Build with `npm run build` and deploy the `dist/` folder to Vercel or Netlify.
